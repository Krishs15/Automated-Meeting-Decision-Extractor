Automated Meeting Decision Extraction System

Paste a meeting transcript and this system will identify sentences containing final decisions using sentence segmentation, TF-IDF, and classification.

Meeting Transcript

How It Works

  1. Segment the transcript into individual sentences
  2. Remove filler / small-talk openers
  3. Detect decision-related language patterns
  4. Classify each sentence with a TF-IDF + logistic regression model
  5. Return numbered decision sentences
